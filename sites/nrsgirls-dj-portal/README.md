# NRSgirls DJ Portal

Root directory for the DJ enrollment and dashboard site.

## Purpose

This site contains:
- DJ signup and onboarding flow
- Upload form with metadata and rights-check checklist
- Dashboard: upload history, analytics, monetization settings

## Deployment

This directory is configured for GitHub Pages deployment.
